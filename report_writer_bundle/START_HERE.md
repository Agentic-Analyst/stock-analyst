# Report Writer Bundle

Open this first:

- `report/final_report_writer_handoff.md`

That file is the single entry point for the bundle. It explains:

- what the project ultimately became,
- which artifacts are primary evidence,
- what the final claims and non-claims are,
- which run roots matter,
- where the prompts and attack templates live,
- and the exact Tier 1 / Tier 2 / Tier 3 reading order for writing the report.

This bundle already contains the files referenced in that handoff, including:

- `report/` docs and evidence packaging
- frozen `runs/` used in the final evidence set and rigor supplements
- `src/security/` plus key VYNN source files for prompts / templates / logic
- benchmark `datasets/` needed for attack materials and reproducibility
- optional presentation context:
  - `presentation/vynn_security_presentation_v3.pptx`
  - `scripts.md`
  - `review5.md`
  - `review6.md`
